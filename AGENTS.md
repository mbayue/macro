## Agent skills

### Issue tracker

Issues and specs are tracked in GitHub Issues (`mbayue/macro`) via `gh`. See `docs/agents/issue-tracker.md`.

### Triage labels

Uses the default five triage labels (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout (`GLOSSARY.md` and `docs/adr/` at the repo root). See `docs/agents/domain.md`.

### Design system

When building or reviewing `/app/` UI, tokens, typography, or CSP styling, read `DESIGN.md`. For the home, privacy, terms and 404 pages, read `docs/landing.md`.

### Architecture & coding standards

For module boundaries and commands see `docs/architecture.md`; for review-time UI, telemetry, and React 19 standards see `CODING_STANDARDS.md`.

### Firebase

For Firebase AI Logic, App Check, Remote Config, Cloud Firestore (`firestore.rules`), or CLI deploys (`npx -y firebase-tools@latest`), load `firebase-basics`, `firebase-ai-logic-basics`, `firebase-remote-config-basics`, `firebase-firestore`, `firestore-rules-creation`, or `firebase-security-rules-auditor` first.

### Windows, screenshots and deploy

Before running shell commands, worktrees, dev servers, screenshots or a deploy on this Windows PC, read `docs/agents/windows.md`.

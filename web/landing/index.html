Before you ask

Can Macro test my own site today?

Not yet. The demo can only reach one demo shop. Your own sites need domain verification with a DNS TXT record, which is the next thing being built.

What stops someone using it as a DDoS tool?

The target must match a verified site exactly, and the policy gate caps users and duration in code. The sandbox network has no route out except a proxy that allows HTTPS to that one host.

What does the AI decide, and what does code decide?

The AI drafts the plan, suggests whether to continue after each stage, and writes the explanation. The target, limits, script, sandbox settings and stop-on-failure rule are fixed code.

Can the AI make up numbers in the report?

Every number in the AI text is checked against the measured values and the plan. If one does not match, the explanation is withheld and a plain template is shown instead.

What runs inside the sandbox?

k6, pinned by digest, under gVisor, as a non-root user with a read-only filesystem, 1 GiB of memory, one CPU and no secrets. Each stage gets a fresh sandbox that is removed afterwards.

Where does the traffic come from?

One Vultr machine in Singapore. At high user counts the load generator itself can become the limit, and the report says so.

Which models does it use?

Vultr Serverless Inference: minimax-m3.1-flash, with one fallback attempt on mimo-v2.6-flash. Every call is listed in the run with its latency and tokens.
